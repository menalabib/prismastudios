The Studio

Prisma Studios is a recording and production studio built around the artist. The vocal booth is set up for clean, close takes through a Neumann TLM 103, with a window to the control room. In the control room, ADAM monitors for mixing sit alongside Dynaudio BM15A monitors, and a Mackie mixing board keeps things hands-on. Guitars, keys and plenty more gear are always within reach, so an idea can go from first spark to finished song without leaving the room.
